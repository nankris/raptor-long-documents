# 074r: RAPTOR on full NarrativeQA stories

## Preregistered hypothesis and decision rule (before experiment execution)
Hypothesis: the original Qwen3-4B-Instruct-2507 + bge-small RAPTOR pipeline improves question answering over flat leaf retrieval on genuine full stories exceeding 20,000 words and the configured usable reader context (2,048 total tokens). All three arms receive at most 1,500 Qwen context tokens: flat chunks, collapsed RAPTOR tree (leaves plus summaries), and the first 1,500 tokens of the full story. This tests an explicitly constrained reader, not a claim that these stories exceed Qwen's native maximum context.

Use NarrativeQA validation full stories, never Wikipedia summaries, deterministically selected by document ID. Round 1: at least 150 questions across at least 6 eligible stories. Native free-answer QA uses greedy generation, at most 64 tokens, identical prompts. Binary correctness is maximum normalized token F1 against the two reference answers >= 0.5. Report continuous F1 too; this correctness proxy is imperfect and must be disclosed. Primary comparison: RAPTOR vs flat using exact two-sided McNemar (binomial on discordant pairs). PROVEN if RAPTOR wins significantly; DISPROVEN if flat wins significantly; otherwise STILL INCONCLUSIVE. A nonsignificant tie does not prove equality. Per-round significance threshold 0.025 accounts for two planned looks (familywise <=0.05). Truncated context is a secondary descriptive comparator; report its McNemar p, without expanding the primary claim. Report paired bootstrap 95% CIs (10,000 draws, seed 74) for accuracy differences and story-cluster bootstrap sensitivity, since questions share stories.

If round 1 is inconclusive, redesign once by doubling to >=300 questions and >=12 stories (adding previously unseen stories; reuse round-1 predictions). Apply the same threshold and report both rounds. Stop after round 2 even if inconclusive. Never choose questions using observed predictions. Infrastructure failures are not completed statistical rounds.

Original pipeline retained: 100-word leaves, bge-small embeddings, KMeans groups of ~5, up to 3 summary levels, Qwen3-4B fp16 reader/summarizer, original concise fact-preserving summary prompt. Retrieval budgets include separators and are verified with the reader tokenizer. Log document lengths, token lengths, retrieved levels, predictions and references, model/software versions, timing. Public sources only.
