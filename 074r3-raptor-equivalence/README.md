## Fixed decision rule
Primary estimand: paired mean accuracy difference RAPTOR minus flat in percentage points. Single final analysis after all validation questions (or budget cutoff); do not stop based on observed accuracy. Bootstrap seed 74, 20,000 replicates. Report paired question bootstrap and article-cluster bootstrap (resample articles, retain all their questions, ratio of total correct differences to total questions), each 95% and 90% percentile intervals. Exact two-sided McNemar is descriptive corroboration.

PROVEN (superiority) if BOTH 95% lower bounds >0. DISPROVEN (inferiority) if BOTH 95% upper bounds <0. Otherwise DISPROVEN (equivalent within margin) if BOTH 90% intervals lie strictly inside [-3,+3] points: bootstrap TOST inversion at alpha .05. A three-point gain is the minimum practical improvement worth tree construction, summary inference and storage here; equivalence does not mean mathematical equality. Also DISPROVEN (no practically meaningful advantage) if BOTH one-sided 95% upper bounds <+3 points, even if the lower equivalence boundary is unresolved. This last prespecified non-superiority endpoint can conclude that the practical benefit claim fails without asserting symmetric equivalence. Superiority takes priority if both superiority and practical non-superiority hold; report effect size regardless. If neither endpoint holds, STILL INCONCLUSIVE only on exhausting the fixed compute/time budget; no forced conclusion from nonsignificance.

## Power and budget
For paired differences, variance approximately equals discordance q under zero effect. Using earlier NarrativeQA q=38/300=.127, SE=sqrt(.127/2086)=.0078. At true zero, TOST power approximately 2 Phi(.03/SE-1.645)-1 =97.2%; allowing design effect 1.5 gives ~86.5%. At q=.20 and design effect 1.5, power ~61%; one-sided non-superiority power ~80%. These are planning assumptions, not guarantees. At n=1000 and q=.127, TOST power is only ~69%, motivating the full split. A true +3-point effect has roughly 80% power under q=.127 and design effect 1.5 for a two-sided 5% test. Compute cap may prevent full completion; retain every paired observation and disclose reduced power.
